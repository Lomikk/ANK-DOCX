# Нативные формы страниц СТО ЮУрГУ 04–2008

`title.xml`, `first.xml`, `following.xml` — подготовленные колонтитулы Word с DrawingML-объектами, полученные из преподавательского шаблона. Они устанавливаются вместе с расширением. Исходный заполненный DOCX и соседний репозиторий ANK для сборки работы не нужны.

Источник: `Шаблон оформления курсовой работы.docx`, SHA-256 `E367ECB5705CA408E18514015B4CB89DE9C7BAAEFEBCCF8F128E23F36272DEAA`. Разбор исходника: `docs/research/STO04_TEMPLATE_REVIEW.md` репозитория. Пользователь явно выбрал нормативные размеры и состав СТО вместо сохранения локальных отклонений образца.

Воспроизведение подготовки из корня репозитория:

```powershell
.\tools\academic-docx.cmd prepare-sto04 "D:\Repos\Курсовой проект\Шаблон оформления курсовой работы.docx" "quarto\_extensions\academic\page-templates\sto04"
```

Команда принимает только проверенный хэш исходника. Подготовка реализована на C# в `TechnicalPageTemplates`, сохраняет исходник и извлекает его нативные линии и фигуры. Рамка установлена в x=20, y=5 мм, размер 185 × 287 мм. Сетка форм приведена к размерам рисунков А.2/А.3 СТО: 185 × 40 и 185 × 15 мм. В форме 2 четыре строки подписантов; добавленная в преподавательском файле строка рецензента удалена. Векторные границы сетки нормализованы, текстовые поля имён имеют нормативную ширину 23 мм.

Старые имена, даты, отметки выполнения, код документа и статистические числа удалены. Вместо данных используются нативные текстовые content controls `AcademicStamp.*`. `PAGE` и `NUMPAGES` — настоящие поля Word. Подписи, даты подписания, литера и неизвестное утверждающее лицо остаются незаполненными. Служебные графы штампа используют явный чёрный шрифт Arial размером 7–14 пт по вместимости графы; основной текст и научные таблицы сохраняют свои общие стили. Полное соответствие начертания чертёжных шрифтов ГОСТ 2.304 отдельным испытанием не подтверждено.

DrawingML используется как основное представление для поддержанного Word 16. Исходный VML fallback удаляется при подготовке, чтобы значения слотов имели одну исходную реализацию; Word при сохранении может сформировать совместимое альтернативное представление снова. Идентификаторы фигур разведены между тремя компонентами. Стили исходного заполненного документа не импортируются.

`DocumentPageLayout` подставляет данные, создаёт разделы и резервирует место под штампы до разделения длинных таблиц. Нативное поле `PAGE` контекстно вычисляется на каждой печатной странице. Число `NUMPAGES` дополнительно сверяется с итоговой пагинацией Word.
