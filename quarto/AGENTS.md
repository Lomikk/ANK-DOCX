# Подготовка работы ANK

- Начни с [каталога примера](EXAMPLE_GUIDE.md): `chapters/main.qmd` содержит все поддержанные элементы и исполняемый расчёт R. При добавлении новых возможностей поддерживай пример и каталог в актуальном состоянии.
- Содержательный текст редактируй в `chapters/main.qmd`. Все разделы могут находиться в одном файле; используй обычные заголовки Quarto. Служебную setup-ячейку сохрани.
- Сведения о работе заполняй в `metadata.yml`. `academic.profile` выбирает готовый профиль: `coursework` или `referat`. Состав сопроводительных листов задаётся расширением; не добавляй их в текст и не редактируй `_extensions/` для конкретной работы.
- Сейчас все сопроводительные листы — явно обозначенные заглушки. Состав демонстрационных профилей не подтверждает требования СТО. Не выдавай такой DOCX за нормативно готовую работу.
- Источники храни в `references.bib`, данные — в `data/`, внешние изображения — в `figures/`. Пути вычисляемого кода отсчитываются от корня проекта. Markdown-пути изображений внутри `chapters/main.qmd` задавай относительно файла, например `../figures/plot.svg`.
- Математику записывай стандартной LaTeX-разметкой Quarto; самостоятельные формулы — `$$...$$ {#eq-name}`. Для ссылок используй `@eq-name`, `@fig-name`, `@tbl-name`, `@sec-name`; для источников — `[@source-id]`. Номера вручную не добавляй.
- В одном файле приложения задавай заголовками `# Название {.appendix #sec-app-name}` после основной части и библиографии. Буквы и номера таблиц задаёт расширение; `.unnumbered` к приложению не добавляй. Все последующие заголовки первого уровня также должны быть приложениями. Используй ссылки `@sec-app-name` без ручной буквы.
- Для таблиц используй flextable и общую функцию `ank_style_table()`. Для графиков — ggplot2; общая тема и SVG-драйвер уже настроены. Модель и исходные данные определяй один раз. TikZ, PGFPlots и компиляция TeX для графиков не используются.
- Исследуемую программу сохраняй на её языке. Неисполняемый листинг не превращай в вычисляемую ячейку; используй стандартные `#lst-...`, `lst-cap` и ссылку `@lst-...`.
- Один раз восстанови зависимости: `Rscript --vanilla tools/install.R`. Затем запускай `quarto render`. Нужны R, Quarto, rsvg-convert и опубликованное приложение `academic-docx` в PATH либо `ACADEMIC_DOCX_SERVICE` с путём к EXE. Настольный Word обязателен для готового DOCX.
- Исправляй ошибки по диагностике. `ACADEMIC_SKIP_WORD=1` создаёт только диагностический промежуточный документ с известными ошибками схемы. Пересборка заменяет ручные правки DOCX.

Подробные правила и ограничения: https://github.com/Lomikk/ANK-DOCX/tree/main/docs
