# Документация проекта

Действующий формат — `academic-docx`: единый Quarto Starter с чистым содержанием, knitr, R и flextable. Полная учебная работа хранится только в `Workspaces/Пример/`, зависимости новых работ используют общий кэш renv. Новые работы используют `chapters/main.qmd`; Book сохранён как многофайловый интеграционный пример. Установка и сборка описаны в [основном README](../README.md), авторский интерфейс — в [инструкции](AUTHORING.md).

Графики строим преимущественно ggplot2 с экспортом SVG через svglite. TikZ, PGFPlots и quarto_tikz исключены из рабочего стека; соответствующий отчёт ниже сохранён как история завершённого исследования.
