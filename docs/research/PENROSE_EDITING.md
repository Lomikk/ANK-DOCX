# Локальный редактор Penrose и сохранение ручных правок

1 ноября 2026 года. Локальный сервис 0.4.12, расширение 0.4.9.
Пользовательский выпуск сервиса ещё не опубликован; self-contained сервис собран
в .tools/academic-docx. Базовые авторские команды и ограничения: ../PENROSE.md.

## Основание реализации

Официальные источники: https://penrose.cs.cmu.edu/docs/ref/using и
https://penrose.cs.cmu.edu/docs/ref/Interactivity. Изучены официальный editor/Roger
и закреплённый исходник v3.3.1 (commit 8346c617bc3a56be17f058e1fe68961e282cc4c6).
Выявлено, что опубликованная онлайн-версия не включает Roger-панель: она доступна
в development mode. По уточнению пользователя выбран именно локальный редактор.

Применён официальный исходник editor, опубликованные core/components, Vite,
официальный Roger watch, rsvg-convert и стандартные JSON/XML API C#.
Нового редактора, оптимизатора, парсера Penrose или реестра диаграмм нет.
Небольшой C#-адаптер запускает редактор, импортирует конечный SVG и сохраняет историю.
Локальная конфигурация и два конкретных upstream-пробела подробно описаны в
../../tools/PenroseEditor/README.md. Zip закреплён SHA-256; npm-восстановление — по lock.

## Контракт

- Файлы .trio.json под figures/penrose — единственный каталог диаграмм.
- diagram.edited.svg рядом с diagram.trio.json — сохранённый рисунок для сборки.
- Отсутствие edited.svg означает обычную автоматическую генерацию.
- R pre-render сначала выбирает сохранённый SVG, затем нормализует его для Word.
  QMD-ссылки на .quarto/penrose сохраняются, сырой edited.svg не изменяется.
- Apply проверяет XML и рендеринг SVG до замены; предыдущий файл копируется в .history.
- Generate сначала успешно строит и нормализует SVG, затем сохраняет прежнюю правку
  в истории и возвращает автоматический режим. Сбой оставляет правку на месте.
- Ручная правка не запрещает агенту обновить диаграмму в рамках задачи пользователя.
  Дополнительного согласования из-за наличия edited.svg не вводится.

## Проверено

- C# build и self-contained publish без ошибок и предупреждений.
- 16 целевых проверок Penrose и меню: поиск вложенных trio, имена выходов, история,
  отмена импорта, некорректный SVG, метаданные для загрузки в editor, отказ генерации.
- R-проверка выполнена дважды с сохранённым SVG, испорченным trio и заведомо
  отсутствующими Node/Roger: выходной SVG создан, исходный edited.svg побайтно сохранён.
  Проверке не нужен Word. Для локального R очищены LC_* через LocalToolchain.
- Официальный editor успешно собран Vite: обработаны 1449 модулей, скомпилированы
  основные JS и worker-чанки, включён локальный WASM. Предупреждения upstream MathJax
  об eval и размерах чанков не являются ошибками сборки.
- Установка через C# воспроизведена из закреплённого ZIP и npm lock (341 npm пакет).
- Локальный editor отвечает HTTP 200 на /try/ и модуль App.tsx; в модуле присутствует
  подключение Roger. Оба слушателя привязаны к 127.0.0.1, порты 3000 и 9160.
- WebSocket с Origin локального editor получил два trio работы «Управление данными»
  и агрегированный ответ с Domain/Style/Substance выбранного trio. Другой Origin отклонён.
- Запуск в консоли, Enter и завершение сессии проверены; после выхода оба порта свободны.
  Выявлено и исправлено наследование stdin: Vite больше не забирает клавиатуру меню.
- Команда prepare сформировала превью и SVG с исходниками двух реальных диаграмм.
  Каталог действительно открылся в системном браузере, но основной путь теперь открывает
  HTTP localhost непосредственно в официальном редакторе.
- В реальной работе SVG применён через CLI, затем выполнен полный build. SHA-256
  edited.svg до/после: 94D534E5AFA0A29D61695621EEA3AF525CDF338CE0CB3F8A287230DF3083697B.
  Конечный DOCX: Open XML SDK 0 ошибок. Затем generate вернул автоматический режим,
  прежний SVG сохранён в истории работы. Тестовая правка не выдавалась за правку человека.
- ER Style этой работы адаптирован для перемещения овалов: позиции атрибутов — свободные
  входы с линейными целями относительно владельца. Избыточные попарные ограничения,
  мешавшие решению, убраны. Готовая автоматически рассчитанная схема просмотрена.

## Что не подтверждено

Автоматическое взаимодействие с текущим системным Yandex-браузером было остановлено
инструментом Computer Use: проверка URL для этого Windows-браузера не поддерживается.
Поэтому весь цикл мышью «выбрать trio → перетащить фигуру → Export» в этой сессии
не проверен через UI. HTTP, компиляция frontend, Roger-протокол, CLI Apply и DOCX build
проверены отдельно. Это различие нельзя скрывать общей фразой «вся интеграция проверена».

Официальный импорт SVG заново компилирует вложенные исходники, не восстанавливая
обязательно все перемещения мышью. Сохранённый рисунок для Word при этом не теряется.
Вычисляемые фигуры не становятся автоматически перетаскиваемыми. Сложные произвольные
нотации и автоматическое объединение ручного оформления с новой моделью не проверены.

## Поставка

Исходники, конфигурация и lock-файлы — в репозитории; бинарные файлы и установленный
редактор — в .tools. Новые работы получают R-hook и инструкции из Starter, существующим
работам требуется штатное обновление расширения. Работа «Управление данными» обновлена
командой quarto add из quarto/. Авторские документы других работ не переписывались.


## Проверка браузером после сообщения о белой странице

Во встроенном браузере удалось воспроизвести белую страницу и прочитать реальную
ошибку JavaScript: MathJax components/version.js исполнял eval('require') при
отсутствии PACKAGE_VERSION. Это runtime-ошибка; успешные HTTP-ответы и сборка Vite
её не исключали. Конфигурация Vite теперь задаёт константу из версии установленного
mathjax-full и при преобразовании исходников, и при оптимизации зависимостей.
Исправление применено также в текущую локальную установку.

После обновления страницы проверены видимый интерфейс, вкладка roger, список двух
trio, выбор conceptual/diagram и Compile. ER-схема отображена в Diagram; проверен
увеличенный просмотр. Снимок: Workspaces/Управление данными/.quarto/penrose-editor/browser-verified.png.
Это дополняет прежнюю ограниченную HTTP-проверку реальной проверкой загрузки и
компиляции в браузере. Перетаскивание и экспорт этой проверкой ещё не покрыты.
