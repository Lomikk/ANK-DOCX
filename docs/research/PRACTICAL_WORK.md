# Приёмка локальной практической работы

1 ноября 2026 года. Расширение 0.4.4, сервис 0.4.7. Добавлен только `practical-local`; контрольная исключена по последнему уточнению пользователя.

## Выбранный механизм

Использованы единый Starter, общий каталог `profiles.json`, существующие формы Pandoc и C#-оформление страниц. Источник текста и состава титула — локальный `susu-study-work-v1` оригинального ANK; его TeX-код, инфраструктура и переключатели не переносились. Номер СТО комплекту не приписывается.

Оглавление — штатное `toc` Quarto. CLI записывает `toc: false` только в метаданные новой практической; настройка остаётся авторской и не переписывается при сборке. Формулы, таблицы, ссылки и расчёты используют общий конвейер.

Подтверждённый пробел служебного слоя: оформление титула и страниц ранее запускалось при наличии статистики аннотации. Оно отделено от необязательной аннотации. Для титула без промежуточных листов устранён второй разрыв страницы в соседнем маркере начала текста. Распознавание стилей титула общее для SDK и Word. Остальная обработка R/OOXML не переносилась.

## Результаты

- Практическая без оглавления: 2 страницы — титул и решение. На титуле номер скрыт, основной текст начинается с номера 2; пустой страницы нет.
- Та же практическая с `toc: true`: 3 страницы — титул, оглавление с обновлённой ссылкой на страницу 3 и решение. Нумерация 2/3 видна в нижнем колонтитуле.
- Короткий реферат СТО 17 с тем же решением: 4 страницы; аннотация и её поля статистики сохранены. Это регрессия существующего комплекта, а не новый профиль.
- Во всех трёх DOCX: 0 ошибок итоговой проверки SDK; нативные SEQ/REF, редактируемая математика и flextable. R вычисляет сумму квадратов как 14, результат появляется в тексте и таблице.
- В практической отсутствуют задание, аннотация и её поля статистики. Не требуются реквизиты нормоконтролёра, задания, краткое название вуза и текст аннотации. Title end — страница 1, annotation start в отчёте — null.
- Оба варианта практической экспортированы через Word в PDF; просмотрены все пять страниц. Проверены расположение блоков титула, таблицы, формулы, оглавление и номера. Собственные процессы Word завершились без ошибок.
- Создание через workspace CLI проверено отдельно: пустой `chapters/main.qmd`, `profile: practical-local`, обычный `toc: false`, зависимостей оформления внутри авторского текста нет.
- Общая Lua-проверка прошла для текущих и старых имён комплектов, отказа при конфликте `academic.standard`, отсутствующих метаданных и недопустимых ключевых слов НИР. Практическая успешно создаёт форму без полей аннотации.

Автоматизированная регрессия: `FrontMatterTests`, `ProfilesTests`, `Fixtures/profiles.lua` и `QuartoStarterTests.ShortStudyWorksHaveOptionalContentsAndNoSummaryDependency`. Временные проекты, PDF, PNG, журналы создания, отчёты Word и TRX находятся в игнорируемой `.tools/study-acceptance/`.

Финальный архив прошёл 47 проверок SDK, CLI, локальных инструментов и установки, включая повторную установку и отказ при неверном SHA-256. Сценарий трёх сборок Word проверен отдельно; оформление без аннотации также покрыто при явном выборе оформления страниц и без переданного layout metadata. Локальный сервис обновлён из проверенного архива, каталог CLI содержит практическую и не содержит контрольной.

Это проверка небольшого локального комплекта и изменённых общих механизмов. Требования конкретного преподавателя, произвольно длинные реквизиты и полнота содержания практической этой приёмкой не подтверждаются. Существующие ВКР не расширялись и остаются вне текущей задачи.
