# Подключаемые файлы QMD в обычной работе

1 ноября 2026 года. Проверен стандартный проект `default`, расширение 0.4.7, Quarto 1.10.19, R/knitr, flextable, ggplot2 и настольный Word. Тестовая работа создана отдельно в игнорируемом `.tools/include-acceptance/`; пользовательские работы не менялись.

`chapters/main.qmd` содержит setup и три штатных `{{< include ... >}}`: модель, результаты и приложение. В модели вычисляется набор данных с параметром 7; таблица и график в другом файле и таблица приложения используют тот же набор. В результирующем тексте сумма равна 42. Проверены ссылка на раздел из другого файла, ссылки на таблицу и рисунок, обычное приложение `.appendix` и ссылка на его таблицу. Сборка через workspace build вернула 0; после Word DOCX прошёл Open XML SDK с 0 ошибок. Промежуточный пакет до сохранения Word имеет известные ошибки схемы.

В отрицательном сценарии между H1 и H2 оставлена только скрытая вычисляемая ячейка, а упоминание таблицы перед ней убрано. Обе рекомендации появились в обычной консоли и `build-summary.log`, сборка осталась успешной. Имена включаемых файлов и номера строк рекомендации сейчас не определяют. Первая проверка также обнаружила попадание строк JSON финализации в короткий журнал после рекомендации; разделение сообщений пустой строкой исправлено в расширении 0.4.7.

Это проверка конкретного сценария, не гарантия всех сочетаний включений. [Quarto](https://quarto.org/docs/authoring/includes.html) обрабатывает включения как содержимое основного файла: пути в подключённом тексте отсчитываются от него; метаданные внутри фрагментов могут неожиданно воздействовать на весь документ. Book сохраняется для штатного многофайлового проекта и `book.appendices`.
