# Свидетельства приёмки СТО 04

Основной отчёт: [STO04_PAGE_LAYOUT.md](../../STO04_PAGE_LAYOUT.md).

- `unit.trx`: 19 переносимых проверок пройдено, 8 проверок внешней среды пропущено.
- `integration-first-attempt.trx`: 13 проверок регрессии пройдено; первоначальная проверка технической курсовой отклонена из-за неверного сравнения кеша PAGE. Это исторический неудачный запуск, не итоговый зелёный журнал.
- `layout-final.trx`: четыре проверки оформления после удаления отдельной надписи из исходного колонтитула.
- `technical-final.trx`: итоговый тест двух чистых сборок технической курсовой и отрицательного случая стандарта.
- `baseline.json`, `expanded.json`: финализация Word для 15 и 20 страниц.
- `example-finalize.json`, `example-inspect.json`: поставляемый пример, финализация и проверка научных объектов.
- `geometry.json`: постраничные замеры PDF и проверка печатных PAGE/NUMPAGES. Допуск геометрии 0,1 мм; проверена верхняя граница штампа по векторным линиям.
- `example-export.json`, `expanded-export.json`: экспорт через Word, закрытие документа и собственного процесса.
- `asset-hashes.json`: SHA-256 поставляемых нативных компонентов.

Проверки Word и SDK описывают структуру и пагинацию конкретного корпуса. Отсутствие ошибок схемы не доказывает соблюдение всех норм СТО. PDF и PNG оставлены в игнорируемом `.tools/sto04-implementation/`.
