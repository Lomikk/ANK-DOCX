# Приёмка локальной установки ANK 0.4.3

31 октября 2026 года. Пользовательский setup получает готовый сервис; компиляция выделена в режим разработчика. Сервис 0.4.3 поставляется с .NET Runtime 10.0.14, расширение сохраняет версию 0.4.2. Инструкция — [ENVIRONMENT_SETUP.md](../ENVIRONMENT_SETUP.md).

## Механизм

Использованы штатные `dotnet publish --self-contained`, Windows `curl`, `tar`, `certutil`, renv restore/cache и junction NTFS. Собственный код связывает их с версиями и каталогом клона. В начальном загрузчике нет JSON/YAML-парсера и не требуется .NET: генерируемый `tools/service-release.cmd` содержит адрес, версию и SHA-256 архива. Пакетирование выполняет существующий C#-сервис. В архив входят уведомления .NET и Open XML SDK.

Исправлены два обнаруженных пробела. Установщик R 4.6.1 удалён из текущего каталога CRAN и доступен в версионном архиве. Quarto/Pandoc не загружает Lua-модули из пути установки с кириллицей. Для этого перенесён прежний обход из Book: временная junction с ASCII-путём, отдельная для каждого каталога Quarto. Назначение ссылки проверяется перед повторным использованием; бинарные файлы остаются внутри `.tools`. Общая реализация используется CLI и Book-скриптом.

## Проверки

- **Пять целевых тестов прошли:** окружение дочернего процесса не меняет родительское; сервис запускается без системного .NET в PATH/DOTNET_ROOT; начальный загрузчик принимает правильный архив и повторно использует установку; повреждённый архив отклоняется до распаковки; junction сохраняет буквальные кириллицу, пробелы, `&`, `%TEMP%` и `!` в целевом пути.
- Создан отдельный Git-клон с кириллицей в пути и без установленных инструментов. Сервис установлен из локального релизного архива с проверкой SHA-256. **R, Quarto и SVG-конвертер скачаны заново** с закреплённых адресов и установлены внутрь клона.
- Восстановлены **84 бинарных пакета R**, без Rtools. У Примера и двух новых работ по 84 junction на один кэш в `.tools/renv/` этого клона. Проверены все целевые пути. Новые библиотеки связались с кэшем за **0,47 секунды** каждая.
- В новом реферате выполнены R-расчёт `sum(1:5)`, flextable и ggplot2/SVG; сформирован DOCX **на 6 страницах, 0 ошибок SDK**. Статистика: один рисунок, одна таблица, один источник. Финализатор работает с .NET 10.0.14; собственный процесс Word завершён без ошибок.
- Повторный setup прошёл: архивы повторно не скачивались, авторские QMD и metadata.yml сохранили SHA-256. Пользовательские работы setup не обновляет.

При установке, создании и сборке PATH ограничивался системным каталогом Windows, DOTNET_ROOT указывал на отсутствующий каталог. Это новый клон на имеющейся Windows с Word, **не испытание на чистой виртуальной машине**: SDK и PIA физически не удалялись. Self-contained состав проверен также по runtimeconfig и наличию собственного runtime в распакованном архиве.

Исходник — [environment.qmd](../../tools/AcademicDocx.Tests/Fixtures/environment.qmd), журналы — [evidence/local-environment/](evidence/local-environment/). Тестовые клоны и документы находятся только в `.tools/setup-acceptance/`, архив — в `.tools/releases/`.

## Поставка и границы

Архив собран из коммита `9775402`; последующий коммит фиксирует SHA-256 и приёмку без изменения C#-кода. Выпуск — [v0.4.3](https://github.com/Lomikk/ANK-DOCX/releases/tag/v0.4.3). Размер и контрольная сумма — [artifact.json](evidence/local-environment/artifact.json). Готовый архив в Git не добавляется.

Обходу Quarto нужен записываемый TEMP с ASCII-путём. Старые работы могут сохранять ссылки на прежний кэш; автоматическая миграция не заявляется. Word и шрифты остаются системными зависимостями. Не проверены ARM, другая ОС, сетевой каталог и работа без Word. Все профили заново не пересобирались: алгоритмы документов не менялись.
