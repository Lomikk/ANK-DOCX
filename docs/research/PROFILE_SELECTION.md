# Единый выбор комплекта, 0.4.0

31 октября 2026 года. Реализован первый этап [плана профилей](../PROFILE_DEVELOPMENT.md).

`academic.profile` принимает `coursework-susu-21-2008`, `referat-susu-17-2008`, `coursework-susu-04-2008`. Поле `academic.standard` необязательно; старые короткие имена разрешаются в том же каталоге, конфликт стандарта с полным именем вызывает ошибку.

Один `profiles.json` содержит фиксированные поддержанные комплекты, их формы, группы обязательных реквизитов и оформление страниц. JSON выбран ради штатных `quarto.json` и `System.Text.Json`. Quarto profiles сами по себе переключают проектные конфигурации, но не задают контракт наших служебных листов; стандартный QMD и проект Quarto сохранены. Новый формат авторского текста и универсальная система плагинов не добавлены.

`profile.lua` разрешает выбор; `front-matter.lua` проверяет данные и вызывает конкретные функции из `forms.lua`. Формы текущих курсовых разделены именами, но переиспользуют общий код там, где их фактическая реализация совпадает. Это структурное изменение не заявляет устранения всех нормативных расхождений бланков СТО 04/21. Научные объекты не получили отдельных реализаций.

C# больше не перечисляет допустимые нормативные пары: `DocumentPageLayout` получает поддержанный `PageLayout` — `plain-body`, `plain-after-title`, `technical`. `Standard` и полный `Profile` сохраняются как диагностические сведения. Изменение внутреннего JSON требует совместных версий расширения и сервиса 0.4.x. Команда `ANK-DOCX.cmd profiles` и меню читают тот же каталог; `new --profile` записывает полное имя только в свежесозданную работу. Имеющиеся работы автоматически не мигрируются.

Выполнены целевые проверки без полной сборки документа:

- Фильтр `tools/AcademicDocx.Tests/Fixtures/profiles.lua` запущен через Pandoc из Quarto 1.10.19 с заполненными метаданными учебного примера. Все три полных имени дают те же Pandoc-блоки, что их старые сочетания; проверены соответствие внутренних параметров страниц, отказ несовместимых вариантов и диагностика отсутствующей аннотации.
- Пять переносимых тестов каталога и SDK-оформления пройдены; журнал локально в `.tools/profile-selection/selection.trx`.
- Служебное приложение опубликовано без ошибок компиляции. Word и полный R/Quarto-конвейер не запускались; новая пагинация и визуальный вид не объявляются проверенными этим прогоном.

Следующий этап — НИР по СТО 19 с собственными формами и фактическими границами частей. Сейчас этот комплект в каталоге отсутствует.
