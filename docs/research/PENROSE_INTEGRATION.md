# Penrose: установка и автоматическая диаграмма в DOCX

31 октября 2026 года. Сервис 0.4.4, расширение 0.4.3. Добавлены локальные Node.js 24.22.2 и `@penrose/roger` 3.3.1; исходники диаграмм находятся отдельно от QMD, SVG создаются штатным pre-render Quarto. [Инструкция автора](../PENROSE.md).

## Выбор средства

Рассмотрены [официальные CLI и три языка Penrose](https://penrose.cs.cmu.edu/docs/ref/using), [публичный API](https://penrose.cs.cmu.edu/docs/ref/api) и [скрипты проекта Quarto](https://quarto.org/docs/projects/scripts.html). Отдельной подтверждённой интеграции Penrose/DOCX в Quarto не найдено. Применён официальный roger, не собственный компилятор, оптимизатор или синтаксис QMD. MIT-лицензия допускает этот способ использования; установленные пакеты содержат уведомления, в учебном примере сохранена лицензия исходного примера Penrose.

У Penrose стандартные Domain, Substance, Style и связывающий `.trio.json`. По решению пользователя они хранятся под `figures/penrose/<имя>/`. В `chapters/main.qmd` остаётся обычная Markdown-ссылка на `.quarto/penrose/<имя>/diagram.svg`. Общий pre-render повторяет дерево путей; реестр исходников и собственный парсер не добавлены. Если входных диаграмм нет, Node не вызывается.

## Два подтверждённых пробела

1. Стандартное дерево npm зависимостей roger 3.3.1 позволяло рендерить Equation, но Text падал с null canvas-контекстом (`textBaseline`). Явные корневые canvas 3.2.3 и jsdom 22.1.0 с `npm ci --legacy-peer-deps` дали рабочий общий DOM/canvas. Все версии закреплены lock-файлом; install script разрешён только для canvas 3.2.3. Код Penrose не менялся. Setup проверяет настоящий canvas-контекст.
2. Word игнорировал CSS-сокращение `font`, выдаваемое Penrose, и уменьшал буквы. Штатный `rsvg-convert --format svg` перевёл надписи в контуры; итоговый SVG содержит 6 path и ни одного text. Собственный CSS/SVG-парсер не понадобился. Подпись и ссылка на рисунок остаются обычными полями ANK.

Это дополнительные интеграции для установленных инструментов; численные графики и нормирование документа сохраняют общую реализацию.

## Приёмка

- Чистый npm-prefix восстановлен по lock-файлу: **173 пакета за 16 секунд**. В PATH были только локальный Node и системный каталог Windows, без Python/MSVC. Native canvas использовал готовую сборку. Глобальные Node/npm-пакеты не менялись.
- Проверены Equation и Text, отдельные файлы и `.trio.json`. Фиксированная variation дала одинаковый SHA-256 исходного SVG после чистой и основной установок. Браузер и TeX-компилятор не требуются проверенному CLI.
- Полный учебный Пример собран с автоматическим pre-render: **19 страниц, 5 рисунков, 3 таблицы, 3 источника, 2 приложения, 0 ошибок SDK**. Страница 11 содержит новую диаграмму, подпись «Рисунок 5» и обновлённую ссылку. Собственные процессы Word закрылись без ошибок.
- Из Word экспортирован PDF. Просмотрены страницы документа и отдельно диаграмма после нормализации. В области диаграммы сохранены векторные кривые, растровых объектов там нет; имеющиеся растровые объекты страницы относятся к штампу ниже. Буквы читаемы и соответствуют геометрии.
- Ошибочный Style завершает pre-render с кодом 1 и сохраняет диагностическое сообщение компилятора. Прежний SVG не заменяется, но сборка не продолжается с ним как с результатом. Пустой проект проходит шаг без Node и без файлов диаграммы.
- Пять целевых C#/bootstrap тестов прошли, включая установку готового сервиса без системного .NET в PATH, контроль SHA-256, повторный запуск и безопасность junction-пути. R-рендер не получил собственного движка knitr.

Журналы — [evidence/penrose/](evidence/penrose/); входной пример — [figures/penrose/sets/](../../Workspaces/Пример/figures/penrose/sets/). Временные проекты, исходные/итоговые SVG, PNG и PDF находятся в `.tools/penrose-probe/`, не в Starter. Новые работы остаются чистыми.

## Поставка и границы

Архив сервиса собран из `78075df`; следующий коммит фиксирует его SHA-256 и приёмку без изменения C#-кода. Выпуск — [v0.4.4](https://github.com/Lomikk/ANK-DOCX/releases/tag/v0.4.4). Node скачивается из официального Windows ZIP с закреплённым SHA-256; пакеты восстанавливает npm в `.tools/penrose/`, кэш — `.tools/npm-cache/`.

Проверена Windows x64 и один содержательный пример, не все типы диаграмм Penrose. Выбор удачной композиции и смысл отношений остаются задачей автора. Старые работы не переписываются автоматически; для них требуется подключить pre-render и обновить установленные служебные файлы по инструкции. Унаследованное ограничение Quarto на ASCII-путь TEMP сохраняется.
