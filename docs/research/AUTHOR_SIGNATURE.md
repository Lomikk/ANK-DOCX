# Подпись автора поверх линии

4 ноября 2026 года. Расширение 0.4.10, локально собранный сервис 0.4.14,
Quarto 1.10.19, Word 16.0.20326.

Настройка и границы поддержки — [FRONT_MATTER.md](../FRONT_MATTER.md#подпись-автора).
Проверена подпись только студента: она накладывается поверх сохранённой линии
`____________`; пересечение штрихов с соседним текстом допустимо по прямому
указанию пользователя. Подписи преподавателей, даты и технические штампы
не заполняются. Личное изображение хранится только в игнорируемой локальной
работе; поставляемый пример содержит отдельный искусственный образец.

## Выбор механизма

Использованы штатные [Pandoc Image](https://pandoc.org/lua-filters.html#pandoc.image)
и [размеры изображений](https://pandoc.org/MANUAL.html#extension-link_attributes).
Pandoc встраивает SVG и резервный PNG через уже проверенный rsvg-convert.
Quarto преобразует путь `image` из metadata.yml для вложенного входного QMD;
добавлять к нему `quarto.project.offset` повторно нельзя.

Встроенное изображение увеличивало высоту строки. В конкретном задании
это воспроизвело переход на дополнительную страницу. Главное ограничение
для принятого требования — штатный Image не обеспечивает наложение на
сохранённую линию. Поэтому небольшой `AuthorSignatureFormatting` переводит
его в стандартный [DrawingML anchor](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.wordprocessing.anchor):
относительно символа и строки, без обтекания, с сохранением графики,
идентификаторов и связей Pandoc. Интервалы и текст абзаца не меняются.
Специальные обходы высоты изображения в WordFrontMatter не потребовались.
Новые зависимости и собственный writer не добавлены.

## Проверенный результат

- Lua-проверка всех пяти комплектов: подпись включена и выключена, ровно
  одно место на титуле и одно в задании при его наличии, только строки автора.
  Отдельно проверены неверные ширины, отсутствующий файл и пустой image;
  всего 16 проверок. Это проверка генерации форм, а не приёмка всех пяти
  комплектов в Word.
- Регрессия `ShortStudyWorksHaveOptionalContentsAndNoSummaryDependency`
  прошла после окончательного изменения: практическая без подписи,
  практическая с подписью и реферат с подписью. Проверены сохранённая линия,
  плавающий anchor без обтекания, отсутствие подписи у преподавателя,
  число страниц и успешная SDK-валидация.
- Полная обычная сборка локальной технической курсовой СТО 04:
  `build-summary.log` без ошибок и предупреждений, 25 страниц,
  титул на странице 1, задание на страницах 2–3, аннотация на странице 4.
- Open XML SDK после сохранения Word: 0 ошибок. Изображение подписи
  присутствует ровно дважды, исходный SVG сохранён в пакете без изменения.
  Научная статистика осталась прежней: 2 рисунка, 11 таблиц,
  6 источников, 7 приложений.
- Экспорт PDF через Word и растеризация Poppler 120 dpi: изменились только
  страницы 1 и 3, остальные 23 страницы побитно совпали с прежним результатом.
  Обе изменённые страницы просмотрены: подпись пересекает сохранённую линию,
  поля преподавателей пусты. На страницах 1 и 3 PDF нет растровых Image XObjects;
  отображаемая подпись сохранилась векторной.
- Подготовленный renderer навыка documents недоступен из-за отсутствия
  LibreOffice в Windows PATH; просмотр выполнен через целевой Word и Poppler.

Сценарий `IndependentProjectsUseProfilesAndFindTheServiceOnPath` остановился
до сборки на существующей проверке наличия jsonlite в локальном каталоге renv:
восстановление сообщило о синхронизированной библиотеке, но ожидаемого
каталога тест не нашёл. Это не результат проверки подписей; восстановление
окружения этого сценария не включено в задачу.

Локальные свидетельства: `build/author-signature/inspection.json`,
`forms-probe.txt`, `test-results/`, экспорт Word и изображения страниц.
Они не поставляются в Git вместе с личной подписью.
