# Приложения в Quarto Book / DOCX

Основание: [СТО ЮУрГУ 04–2008](https://www.susu.ru/sites/default/files/book/standart_kursovoe_i_diplomnoe_proektirovanie_04-2008_yuurgu_1.pdf), пункты 4.14–4.15. Для структуры исходников используется [штатный `book.appendices` Quarto](https://quarto.org/docs/books/book-structure.html).

## Нормативное правило

- Каждое приложение начинается с обозначения `ПРИЛОЖЕНИЕ А` по центру верхней части страницы; тематический заголовок — следующей строкой, с прописной буквы. Даже единственное приложение обозначается буквой А.
- Приложения обозначают прописными русскими буквами, исключая Ё, З, Й, О, Ч, Ь, Ы, Ъ. СТО разрешает и латинские буквы, кроме I и O. Приложения идут в порядке первых ссылок на них в работе; ссылки должны быть на все приложения.
- В оглавлении перечисляют обозначения и названия приложений. Нумерация страниц продолжается из основной части. Разделы внутри приложения при необходимости нумеруют отдельно.
- Таблицы и рисунки нумеруют *внутри приложения*: `Таблица А.1`, `Рисунок Б.2`. Для многостраничного приложения на следующих страницах требуется справа вверху `Продолжение приложения А` (на последней странице образцы СТО также показывают `Окончание приложения ...`).
- Программы и вспомогательные расчёты разрешено выносить в приложения. Приведённый СТО не задаёт конкретного шрифта, цветовой схемы или рамки для листинга.

## Реализовано в действующем конвейере ANK

1. Агент объявляет приложения стандартным `book.appendices` в `_quarto.yml`, а в каждом файле пишет один заголовок `# Название {#sec-id}`. Файлы идут в порядке ссылок. Новый обязательный синтаксис QMD не вводится.
2. Lua-фильтр читает порядок приложений из метаданных Book. Финализатор Word переносит обозначение и название на отдельные строки, центрирует заголовок, начинает приложение с новой страницы, сохраняет ссылки и общую нумерацию страниц.
3. Для таблиц и рисунков приложения используются отдельные Word-последовательности `SEQ` с номерами вида `А.1`, `Б.1`; закладка охватывает полный номер, поэтому штатное поле `REF` возвращает и букву, и цифру. Буква назначается при **новой сборке Quarto**, а не при ручной перестановке страниц в Word.
4. Ссылка `@sec-id` на приложение получает подпись `приложение А`, а листинги используют штатную нумерацию Quarto (`A.1` в его выводе). В Quarto-файлах агент не вводит номера вручную.

## Границы текущей реализации

- **Автоматическая надпись на каждой следующей странице многостраничного приложения не реализована.** Для этого понадобится отдельная Word-пагинация. Не имитируй продолжение обычным абзацем: положение зависит от фактических разрывов страниц.
- Стандартная нумерация листингов Quarto (`A.1`) не является динамическим полем `SEQ` Word. Приведение их к русской букве и проверка при перестановке остаются отдельной задачей. Формулы сохраняют общую нумерацию ANK; приложение не вводит для них неподтверждённое обязательное правило.
- Предполагается ровно один заголовок первого уровня `#` в каждом файле приложения, а вложенные разделы оформляются `##` и глубже. Приложения помещаются **после** основных глав стандартным механизмом Book.
- Проверка порядка первых ссылок, наличия ссылок на все приложения и точного содержания оглавления в произвольном Word пока не реализована как диагностическое правило. Эти требования остаются в инструкции агенту.

Копируемые примеры: `academic/examples/appendix-a.qmd` и `academic/examples/appendix-b.qmd`; настройка приведена в `academic/AGENT_GUIDE.md`.
