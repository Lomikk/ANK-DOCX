# Приложения в однофайловом QMD и Quarto Book / DOCX

Основание: [СТО ЮУрГУ 04–2008](https://www.susu.ru/sites/default/files/book/standart_kursovoe_i_diplomnoe_proektirovanie_04-2008_yuurgu_1.pdf), пункты 4.14–4.15. Для однофайлового Starter используется [документированный класс заголовка `.appendix`](https://quarto.org/docs/authoring/appendices.html#custom-appendix-sections), для Book — [штатный `book.appendices`](https://quarto.org/docs/books/book-structure.html).

## Один main.qmd

После заключения и списка литературы добавьте заголовки:

```qmd
# Вычислительный код {.appendix #sec-app-code}

Текст, таблицы и листинги приложения.

# Дополнительные данные {.appendix #sec-app-data}
```

Ссылки из основной части: `@sec-app-code`, `@sec-app-data`. Буквы не пишутся вручную. Используйте заголовок первого уровня, не добавляйте `.unnumbered`; все следующие заголовки первого уровня также должны быть приложениями. Подразделы оформляются `##` и глубже.

Для подразделов в однофайловом примере используйте `.unnumbered`, например `## Экспорт результатов {.unnumbered #sec-app-export}`. Автоматическая буквенная нумерация разделов вида А.1 в Word пока не реализована; обычное наследуемое число основной части нельзя выдавать за номер раздела приложения.

Штатный Quarto 1.10.19 трактует `.appendix` как приложение для HTML; узкая проба DOCX показала обычный заголовок и обычную нумерацию объектов. ANK читает этот стандартный класс из AST и передаёт заголовки в ту же обработку Word, которую использует Book. Отдельный реестр исходников или новый авторский синтаксис не вводится. Пример: [main.qmd](../Workspaces/Пример/chapters/main.qmd), каталог элементов — [Каталог примера](../Workspaces/Пример/README.md).

## Нормативное правило

- Каждое приложение начинается с обозначения `ПРИЛОЖЕНИЕ А` по центру верхней части страницы; тематический заголовок — следующей строкой, с прописной буквы. Даже единственное приложение обозначается буквой А.
- Приложения обозначают прописными русскими буквами, исключая Ё, З, Й, О, Ч, Ь, Ы, Ъ. СТО разрешает и латинские буквы, кроме I и O. Приложения идут в порядке первых ссылок на них в работе; ссылки должны быть на все приложения.
- В оглавлении перечисляют обозначения и названия приложений. Нумерация страниц продолжается из основной части. Разделы внутри приложения при необходимости нумеруют отдельно.
- Таблицы и рисунки нумеруют *внутри приложения*: `Таблица А.1`, `Рисунок Б.2`. Для многостраничного приложения на следующих страницах требуется справа вверху `Продолжение приложения А` (на последней странице образцы СТО также показывают `Окончание приложения ...`).
- Программы и вспомогательные расчёты разрешено выносить в приложения. Приведённый СТО не задаёт конкретного шрифта, цветовой схемы или рамки для листинга.

## Реализовано в действующем конвейере ANK

1. В одном файле агент помечает заголовки `.appendix`. В Book объявляет приложения стандартным `book.appendices` в `_quarto.yml`, а в каждом файле пишет один заголовок `# Название {#sec-id}`. Два способа не смешиваются. Порядок должен соответствовать первым ссылкам.
2. Lua-фильтр получает порядок из заголовков одного документа либо метаданных Book. Общая обработка Word переносит обозначение и название на отдельные строки, центрирует заголовок, начинает приложение с новой страницы, сохраняет ссылки и общую нумерацию страниц.
3. Для таблиц и рисунков приложения используются отдельные Word-последовательности `SEQ` с номерами вида `А.1`, `Б.1`; закладка охватывает полный номер, поэтому штатное поле `REF` возвращает и букву, и цифру. Буква назначается при **новой сборке Quarto**, а не при ручной перестановке страниц в Word.
4. Ссылка `@sec-id` на приложение получает подпись `приложение А`, а листинги используют штатную нумерацию Quarto (`A.1` в его выводе). В Quarto-файлах агент не вводит номера вручную.

## Границы текущей реализации

- Автоматические надписи продолжения реализованы для `research-susu-19-2008` (см. ниже). Для остальных комплектов их пока нет, в том числе для технических страниц с рамками. Не имитируй продолжение обычным абзацем: положение зависит от фактических разрывов страниц.
- Номера листингов Quarto не являются динамическими полями `SEQ` Word: в Book это `A.1`, в однофайловом документе — сквозные номера. Приведение их к русской букве и проверка при перестановке остаются отдельной задачей. Формулы сохраняют общую нумерацию ANK; приложение не вводит для них неподтверждённое обязательное правило.
- В Book предполагается ровно один заголовок первого уровня `#` в каждом файле приложения, а вложенные разделы оформляются `##` и глубже. В Starter заголовки приложений находятся в конце одного `main.qmd`.
- Проверка порядка первых ссылок, наличия ссылок на все приложения и точного содержания оглавления в произвольном Word пока не реализована как диагностическое правило. Эти требования остаются в инструкции агенту.

Копируемые примеры: `examples/book/chapters/appendix-a.qmd` и `examples/book/chapters/appendix-b.qmd`; настройка приведена в `docs/AUTHORING.md`.

## Особенности НИР СТО 19

В профиле `research-susu-19-2008` версии 0.4.2 применяются пп. 6.12.1–6.12.3 СТО 19 и выбранные правила старого `susu-vkr-research-v1`:

```qmd
# Исходные данные {.appendix #sec-data appendix-kind="mandatory"}

Материал обязательного приложения.

# Дополнительные пояснения {.appendix #sec-details}

Материал информационного приложения.
```

Атрибут `appendix-kind` допускает `mandatory` и `informational`; по умолчанию — `informational`. В других текущих профилях этот атрибут отклоняется, чтобы не обещать неподдержанное оформление. Буквы и номера страниц автор не вводит.

Перед первым приложением ставится общий заголовок «ПРИЛОЖЕНИЯ» на той же странице. Обозначение, вид в скобках и тематическое название занимают отдельные центрированные строки. В оглавление входят обозначение и название, без строки вида и без отдельной записи общего заголовка.

Каждое приложение — штатный раздел Word с особым первым колонтитулом: первый лист без надписи, последующие — с «Продолжение приложения А» справа вверху. Нумерация страниц сквозная; таблицы используют тот же общий механизм разделения и подписи продолжений. Надпись приложения остаётся колонтитулом, поэтому Word переносит её при изменении пагинации. После перестановки приложений или изменения их состава требуется сборка Quarto для обновления букв и содержимого.

Разметка заголовков выполняется общим `AppendixFormatting`, разделы — `DocumentPageLayout`, записи оглавления создаются штатным `TablesOfContents.MarkEntry`. Отдельного пагинатора приложений нет. Проверочный QMD: [appendices.qmd](../tools/AcademicDocx.Tests/Fixtures/appendices.qmd). Проверены два приложения с переносом текста и таблицы; фактическая приёмка и ограничения — [отчёт](research/APPENDIX_CONTINUATION.md).
