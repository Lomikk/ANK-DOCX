# Выпускная исследовательская работа СТО 19

Экспериментальный комплект версии 0.4.2 выбирается в едином `metadata.yml`:

```yaml
academic:
  profile: research-susu-19-2008
```

Сохраняются общие поля учреждения, автора, руководителя, нормоконтролёра и текста краткого описания (`academic.summary`). Специальность задаётся существующими `academic.direction-code` и `academic.direction`. Полное ФИО остаётся в `author`, краткое — в `academic.author-short`. Для данного комплекта дополнительно заполняются:

```yaml
academic:
  # Добавить к общим полям, сохраняя один блок academic в metadata.yml.
  udc: "..."
  reviewer: {name: "...", position: "..."}
  keywords: ["первое слово", "второе слово", "третье слово", "четвёртое слово", "пятое слово"]
  consultants: [] # Необязательные строки {name: "...", position: "..."}.
  assignment:
    # Дополнить существующий блок assignment, не создавать второй.
    head-of-department: "..."
    head-of-department-position: "Заведующий кафедрой"
    approval-document: "..."
    due-date: "..."
    source-data: "..."
    questions: ["..."]
    illustrations: "..."
    calendar: [{section: "...", due: "...", status: ""}]
```

Данные в примере выше — места для реальных реквизитов; подписи и решения о допуске автоматически не подтверждаются. Ключевых слов требуется 5–15, непустых, строчными буквами. Пустые сведения диагностируются по имени поля.

Комплект создаёт титул с УДК, рецензентом, допуском к защите, руководителем и нормоконтролёром; задание с исходными данными и календарным планом; лист «РЕФЕРАТ» с вычисляемой статистикой и ключевыми словами. Задание переносится по фактическому объёму; число листов не вписывается автором. Выбран однотомный вариант, поэтому в характеристике указана одна часть. Титул должен помещаться на одном листе.

Основной текст — тот же `chapters/main.qmd`. Рисунки нумеруются в пределах раздела через штатные поля Word; таблицы и формулы сохраняют сквозную нумерацию. На титуле, задании, реферате и оглавлении печатные номера скрыты, страницы учитываются; в основной части номер расположен внизу по центру. Рамки СТО 04 не подключаются.

Приложения используют обычные заголовки QMD. Для обязательного приложения добавьте атрибут:

```qmd
# Исходные данные {.appendix #sec-data appendix-kind="mandatory"}
```

Без `appendix-kind` приложение информационное; явное значение — `informational`. На первом листе первого приложения появляется общий заголовок «ПРИЛОЖЕНИЯ», под обозначением каждого приложения — его вид и название. На следующих листах Word автоматически показывает справа вверху «Продолжение приложения А» с нужной буквой. Страницы и записи оглавления формируются при сборке. Для Book тот же атрибут ставится у заголовка файла, включённого в `book.appendices`. Подробности — [APPENDIX_RULES.md](APPENDIX_RULES.md), проверка — [APPENDIX_CONTINUATION.md](research/APPENDIX_CONTINUATION.md).

Формы и выбранные решения перенесены из `susu-vkr-research-v1` оригинального ANK; код TeX и его инфраструктура не устанавливаются. Данные физических подписей и полнота научного содержания остаются обязанностью автора и кафедры. Полное соответствие всех требований СТО 19 не заявляется.
