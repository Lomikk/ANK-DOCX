# Установочные данные Penrose

`package.json` и `package-lock.json` принадлежат локальной среде ANK, не копируются в работы. Setup восстанавливает пакеты штатным `npm ci --legacy-peer-deps` в `.tools/penrose/`, используя Node.js из `.tools/` и локальный npm-кэш.

У roger 3.3.1 обычная npm-установка оставляла несовместимое дерево: CLI использовал canvas 3 и jsdom 22, а peer-зависимости DOM-обвязки разрешались отдельно. Математические метки работали, но Text падал с `textBaseline` у null-контекста. Явные корневые canvas 3.2.3 / jsdom 22.1.0 и legacy-peer-deps дали один проверенный набор; версии и транзитивные зависимости закреплены lock-файлом. Install script разрешён только для canvas 3.2.3. Установка проверяет создание canvas-контекста, а не только наличие файлов.

Глобальные пакеты и отдельный renderer не разрабатываются. Обновление версий требует проверки Text, Equation и SVG в Word. Авторский интерфейс — [PENROSE.md](../../docs/PENROSE.md).
