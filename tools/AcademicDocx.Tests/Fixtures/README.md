# Контрольные входы миграции

- `pagination.docx` — неизменённый вход `build/table-split-qa/three-input.docx` завершённого опыта: 90 строк данных и одна повторяемая строка шапки. Меньшие варианты создаются SDK внутри теста. Это фиксированный тестовый корпус, не зависимость рабочей сборки от build/.
- `book-before-word.docx` — неизменённый промежуточный `examples/book/.quarto/coursework-tables-ready.docx.before-word.docx`: две строки объединённой шапки, 55 формул в длинной таблице и итог. Вход до нормализации Word содержит известные ошибки схемы; итог должен быть корректен.
- `reference-migration-input.docx` — исторический вход проверки редактора из коммита `d793414`, путь `academic/_extensions/academic/academic.docx`, Git blob `08cbc183d05a07a91ad51ef00894a03a97b10f13`. Зафиксирован отдельно, потому что позднейшие изменения листингов в живом reference-docx должны сохраняться SDK и не обязаны совпадать со старым результатом Python.
- `reference-legacy.docx` — результат последнего запуска прежнего Python-редактора перед его удалением. Тест сравнивает с результатом SDK на фиксированном `reference-migration-input.docx` XML документа, стилей, нумерации и колонтитулов, учитывая эквивалентные записи boolean и пространства имён. Python для теста не нужен; ожидаемый legacy-файл при выделении Starter не изменялся.

Файлы сохранены 29 октября 2026 года. Научное содержимое является демонстрационным. Числа объектов в этих фикстурах не объявляются универсальным контрактом документа.
