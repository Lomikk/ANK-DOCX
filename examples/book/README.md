# Интеграционный Quarto Book

Сохранённый многофайловый пример проверяет R, flextable, OMML, SVG, длинные таблицы и нативные поля Word. Новый авторский Starter находится в [quarto/](../../quarto/), его базовый текст — один `chapters/main.qmd`. Book не является обязательным типом работы.

Из корня репозитория:

```powershell
.\setup-academic.cmd
.\build-academic.cmd
.\build-academic.cmd --profile referat
.\build-academic.cmd --profile appendices
```

Setup устанавливает расширение из `quarto/`, копирует его проектную точку входа и восстанавливает R-пакеты. `_extensions/` и `tools/academic.R` здесь — установленные зависимости, игнорируемые Git. Правки оформления делаются только в `quarto/_extensions/academic/`; повторный setup обновляет пример.

Результаты: `_book/coursework.docx` и `_book/referat.docx`. Они используют одно демонстрационное содержание, переключая `academic.profile`. Сопроводительные листы в обоих вариантах — явно обозначенные заглушки. Это не подтверждённый состав листов СТО.

Название, автор и персональные сведения находятся в `metadata.yml`; числовые параметры — в `parameters.yml`. Текст и расчёты — в `chapters/`, их порядок задаёт `book.chapters`. Корневой `index.qmd` — техническая домашняя страница, обязательная для Quarto Book. `execute-dir: project` обеспечивает единый корень путей R, но не объединяет состояние независимо исполняемых глав.

Для приложений используйте штатный `book.appendices`. Примеры `chapters/appendix-a.qmd` и `chapters/appendix-b.qmd` подключаются опциональным Quarto-профилем `appendices`; обычная сборка их не включает. Возможности bundle из коммита `0093eec` сохранены: отдельные обозначения приложений, Word SEQ/REF рисунков и таблиц, заголовки и оглавление. Ограничения и нормативные основания — в [APPENDIX_RULES.md](../../docs/APPENDIX_RULES.md).

Общие Word-стили: TNR 14, одинарный интервал, красная строка 7 мм; конкретные параметры и основания — в [REFERENCE_DOCX.md](../../docs/REFERENCE_DOCX.md). Графики используют ggplot2, SVG/svglite и резервный PNG через rsvg-convert. Библиографию формирует Citeproc с общим CSL расширения. Нативные источники менеджера Word не создаются.

`ank_style_table()` использует flextable autofit по области текста. Word разделяет поддержанные длинные таблицы по фактическим страницам, повторяет шапку и создаёт подписи продолжения/окончания. Вертикальные объединения в теле, вложенные таблицы и строки выше страницы отклоняются. Подробности — в [TABLE_RULES.md](../../docs/TABLE_RULES.md).

Диагностический `ACADEMIC_SKIP_WORD=1` не создаёт готовый выпуск: промежуточный пакет имеет известные ошибки схемы. Финальный DOCX требует настольного Word и приложения 0.2.x. Перед пересборкой закройте целевой файл или задайте другое имя через `--output`. Ручные правки Word не переносятся обратно в QMD.

Инструкция автору: [docs/AUTHORING.md](../../docs/AUTHORING.md). Команды проверки и PDF — в [основном README](../../README.md).
